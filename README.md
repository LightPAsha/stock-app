# Склад запчастин — програма для Raspberry Pi

Локальна програма обліку запчастин: зліва розділи (Drone, GCS, …), посередині деталі з кількістю, справа **+** / **−**.
Працює повністю на самому Raspberry Pi: без інтернету, без сервера, у мережу нічого не відкрито.

Запускається як звичайна програма: іконка **«Склад»** на робочому столі та в меню (Офіс).
Відкривається в окремому вікні без адресного рядка. Закрили вікно — програма закрилась.

## Встановлення (один раз)

Потрібен Raspberry Pi OS **з робочим столом**, Pi 3 / 4 / 5 (краще 64-bit).

```bash
# 1. Інструменти для збірки
sudo apt update
sudo apt install -y openjdk-17-jdk maven     # на новій Raspberry Pi OS (Trixie): openjdk-21-jdk

# 2. Розпакувати проєкт і зібрати встановлювальний пакет
unzip stock-app.zip && cd stock-app
./packaging/pi/build-deb.sh                  # перша збірка на Pi ~5-10 хв (качає бібліотеки)

# 3. Встановити
sudo apt install ./target/stock-app_1.0.0_all.deb
```

Після цього на робочому столі з'явиться іконка **«Склад»**. Якщо Pi при першому кліку спитає «Виконати?», натисніть «Виконати».

> Можна зібрати і на звичайному ПК (Windows/Mac/Linux з Java 17 + Maven): `mvn package`,
> потім скопіювати папку проєкту з `target/stock-app.jar` на Pi і там запустити лише `./packaging/pi/build-deb.sh`.
> Jar однаковий для всіх систем.

**Оновлення версії:** зібрати новий `.deb` і знову `sudo apt install ./target/stock-app_…deb`. Дані при цьому зберігаються.
**Видалення:** `sudo apt remove stock-app` (дані в `~/StockApp` залишаються).

## Де що лежить
| Що | Де |
|---|---|
| База даних | `~/StockApp/data/stock.mv.db` |
| Вивантаження Excel | `~/StockApp/Excel/` |
| Лог (якщо щось не так) | `~/StockApp/stock.log` |
| Програма | `/opt/stock-app/` |

**Бекап:** `crontab -e` → додати рядок `0 3 * * * /opt/stock-app/backup.sh` (щодня о 3:00, зберігає 30 копій у `~/StockApp/backups`).
**Автозапуск при вмиканні Pi:** `mkdir -p ~/.config/autostart && cp /usr/share/applications/stock-app.desktop ~/.config/autostart/`

## Вхід і ролі
При першому запуску створюється адмін **admin** з тимчасовим паролем **admin**. Після першого входу програма одразу просить задати свій пароль (двічі) — без цього далі не пустить.

| Роль | Що може |
|---|---|
| **Адмін** | створювати, перейменовувати й видаляти розділи та деталі; імпорт; керування користувачами |
| **Користувач** | лише **+ / −**, пошук, історія, експорт |

В історії видно, хто натискав + / −. Через 30 хв без дій програма сама виходить з облікового запису.

## Google Таблиці
- **Експорт:** **⬇ Експорт** → файл .xlsx у `~/StockApp/Excel/`. У Google Таблицях: Файл → Імпортувати → Завантажити.
- **Імпорт (адмін):** **⬆ Імпорт** → посилання на Google Таблицю (доступ «Усі, хто має посилання») або файл .xlsx.
  Потрібні колонки **Деталь** і **Кількість** (за бажанням **Розділ**, **Мінімум**). Файл, вивантажений самою програмою, підходить без змін.
  Нові розділи/деталі створюються, кількість наявних стає як у таблиці, нічого не видаляється.

## Можливості
- Розділи та деталі додаються і видаляються прямо в програмі
- **+ / −** з кроком (напр. +10 за раз), в мінус не піде
- Мінімальний залишок: рядок жовтий, коли мало, і червоний, коли 0
- Історія руху по кожній деталі (клік на назву)
- Пошук по всіх розділах
- **⬇ Excel**: аркуш «Усі» + аркуш на кожен розділ, автофільтр, сума, позначки «Мало/Немає»
- Кнопка **⏻ Вийти**

При першому запуску база заповнюється прикладом з дошки (Drone: Gimbal, Rear I, Rear II, Main Fuselage; GCS).
Перший старт на Pi займає ~20–40 с (показується заставка), наступні трохи швидші.

## Якщо згодом захочеться відкривати з телефона
У `src/main/resources/application.properties` змінити `server.address=127.0.0.1` на `0.0.0.0` і перезібрати.
Тоді склад буде доступний у локальній мережі за адресою `http://<IP_Pi>:8080`.

## Для розробника
Шари: `model` → `repo` → `service` → `web`. База H2 у файлі; перейти на PostgreSQL можна заміною драйвера
та `spring.datasource.url`, код не змінюється. Тести: `mvn test`.

| Метод | Шлях | Що робить |
|---|---|---|
| GET | `/api/categories` | розділи |
| POST | `/api/categories` `{name}` | новий розділ |
| GET | `/api/categories/{id}/parts` | деталі розділу |
| POST | `/api/parts` `{categoryId,name,quantity,minQuantity}` | нова деталь |
| POST | `/api/parts/{id}/adjust` `{delta, note}` | + / − |
| GET | `/api/parts/{id}/history` | історія |
| GET | `/api/export.xlsx[?categoryId=]` | Excel |
